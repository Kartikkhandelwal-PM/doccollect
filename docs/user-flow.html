One request, one compliance

Every client gets their own message and their own link. A link works until the last date plus a few grace days.

We never ask the client which request a file is for

We sort what comes in on WhatsApp. If we are not sure we still place it and mark it Check. The CA fixes it with Move.

Nothing is filed until the CA approves

Approved files go to the client’s folder in Document Master. The AI and OCR in the app is a stand-in for now.

Own number or the DocCollect number

Replies in the chat are read only on the firm’s own number. On the DocCollect number, clients use the link only.
