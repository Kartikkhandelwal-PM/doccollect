# DocCollect

Document collection for CAs and tax practitioners: send requests on WhatsApp, receive documents, review them, and keep approved files in a Document Master.

| Folder | What is in it |
|---|---|
| `frontend/` | The app (React). Everything works on sample data. See its README to run it. |
| `backend/` | Empty for now. The server, database and file storage come next. |

The live site is built from `frontend/` and published on GitHub Pages.
